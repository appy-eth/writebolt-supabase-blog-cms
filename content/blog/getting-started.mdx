## Welcome to Writebolt Blog

This is your first article. You can edit or delete it from the admin panel at `/admin`.

## Getting Started

1. **Configure your blog** — Visit `/admin/settings` to set your blog name, layout mode, and social links.
2. **Set up navigation** — Add menu items in the settings page to customize your header navigation.
3. **Write content** — Create new articles at `/admin/new` using the built-in editor.
4. **Enable AI assist** — Add your OpenAI API key at `/admin/settings/ai` for AI-powered writing tools.

## AI Writing Features

This template includes BYOK (Bring Your Own Key) AI features:

- **Generate Draft** — Create a full article draft from a topic
- **Rewrite** — Improve selected text for clarity
- **Expand** — Turn bullet points into full paragraphs
- **Generate Images** — Create featured images with AI
